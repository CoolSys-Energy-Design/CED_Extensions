# Theme

## At a glance

| Use this when | Model impact | Required context |
|---|---|---|
| You want to change the look of CED tool windows. | None. Saves a per-user CED tool setting. | No active project is required. |

## What it does

Opens the shared CED theme picker and saves the selected theme and accent for compatible CED windows.

## When to use it

Use it when the current theme is uncomfortable or when standardizing your personal CED tool appearance.

## Before you start

- No model selection or project is required.

## Steps

1. Run **Theme**.
2. Choose a theme and accent in the picker.
3. Save the selection.
4. Reopen a CED tool window to see the saved appearance where needed.

## Results and verification

The selected theme is saved immediately and is used by CED tools when they open.

## Notes and limitations

- Theme settings are user configuration, not project settings.
- Existing open windows may need to be reopened or refreshed to reflect the change.
