# About

## At a glance

| Use this when | Model impact | Required context |
|---|---|---|
| You need toolbar version, build, author, update, or support information. | None. | No active project is required. |

## What it does

Shows the AE pyTools toolbar version, build, pyRevit version, and listed authors. The window also provides links for updates, bugs, feature requests, Designer Hub, and training.

## When to use it

Use it before reporting a problem or when checking which toolbar build is installed.

## Before you start

- No model selection or project is required.

## Steps

1. Run **About**.
2. Review the version and build information.
3. Use an available link if you need support, training, updates, or request forms.

## Results and verification

The command opens an informational dialog and does not change the model.

## Notes and limitations

- Version and author details come from the command's installed configuration.
- Support links open in your default browser.
