# Designer Hub

## At a glance

| Use this when | Model impact | Required context |
|---|---|---|
| You need CED support, training, ideas, requests, or broader documentation. | None. | Internet access and site permissions. |

## What it does

Opens the CED Designer Hub SharePoint site in your browser.

## When to use it

Use it to report a problem, submit an idea, access training material, or find public tool resources.

## Before you start

- No active project is required.
- Sign in to the organizational site when prompted.

## Steps

1. Run **Designer Hub**.
2. Use the browser page to navigate to the required resource.

## Results and verification

The Designer Hub opens externally; no Revit model data changes.

## Notes and limitations

- Availability depends on network access and your SharePoint permissions.
