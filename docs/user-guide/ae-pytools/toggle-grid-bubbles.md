# Toggle Grid Bubbles

## At a glance

| Use this when | Model impact | Required context |
|---|---|---|
| Grid heads need to be shown or hidden to improve view clarity. | Changes grid-bubble visibility in the active view. | Open the target view and optionally select grids. |

## What it does

Provides controls to show or hide grid bubbles at one or both ends of grids in the active view.

## When to use it

Use it to reduce clutter on a plan or to restore grid bubbles needed for coordination and annotation.

## Before you start

- Open the view whose grid-bubble visibility should change.
- Select grids when a targeted result is needed.

## Steps

1. Open the target view and optionally select grids.
2. On **AE pyTools > Miscellaneous > Views**, click **Toggle Grid Bubbles**.
3. Choose the required bubble visibility option.
4. Review the grid heads in the active view.

## Results and verification

The selected visibility option is applied in the active view. The grid datum is not changed.

## Notes and limitations

- The command affects view-specific grid-bubble display, not grid placement.
- Confirm the result in dependent or related views when those views have separate annotation needs.
