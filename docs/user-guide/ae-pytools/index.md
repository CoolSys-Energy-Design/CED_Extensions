# CED Revit Toolbar Documentation

This is the user guide for all tools in the CED Revit toolbar. The toolbar is delivered through several extensions so discipline-specific tools can be maintained and released independently while still appearing together in Revit.

> [!NOTE]
> Documentation is a work in progress. Existing entries are being revised to provide more meaningful direction, example use cases, and practical guidance, and will continue to be updated in future releases.

## Extensions

| Extension | Focus | Start here |
|---|---|---|
| **AE pyTools** | Shared productivity, support, selection, orientation, tags, revisions, schedules, and views. | [AE pyTools guides](#ae-pytools) |
| **CED ElecTools** | Circuit creation and management, wires, electrical QA, panels, one-line data, and lighting workflows. | [CED ElecTools](../ced-electools/index.md) |
| **CED MechTools** | Piping-system operations, connection utilities, and refrigeration workflows. | [CED MechTools](../ced-mechtools/index.md) |
| **WM Tools** | Refrigeration electrical content, workbook-driven panels and circuits, connectors, and power groups. | [WM Tools](../wm-tools/index.md) |

## How to use this guide

Use the extension list or the viewer navigation tree to find a command. Each page explains the tool's purpose, context, expected result, and important limitations. Search is useful when you know the workflow but not the command name.
